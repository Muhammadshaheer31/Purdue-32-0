# Purdue-32-0
## Project Goal
A java game where you build an all-time Purdue basketball lineup and see if you can go undefeated in college basketball. Every round spins a random season and you draft one player from that season's roster into an open position, (PG-C). Once your lineup is full, the game gives you a team record from 32-0 to 0-32 based on rating

##MVP
Load Purdue player seasons from a CSV file
Spin a random, unused Purdue season and display its roster
Draft one player per position until all 5 spots are filled
Calculate an overall team rating
Simulate a 32-game season and display the final record

## Future Plans
